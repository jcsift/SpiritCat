### 不限速、无倍率是否等于不限流量？

不限速描述的是速度限制，无倍率对应套餐标注的节点 ×1，两者都不等于无限流量。年付小包、Small、Big 分别提供每月 45GB、150GB、300GB，按订单日自动重置；需要更多流量时可购买加油包。

<a id="spiritcat-annual-vs-monthly-plans"></a>

### 年付小包与月付 Small 怎么选？

年付小包需一次支付 **¥85**，每月提供 **45GB**，折合约 **¥7.08/月**；Small 的月付为 **¥25**，提供 **150GB/月**。年付小包适合已确认线路表现且用量较低的用户，月付适合先体验或需要更多流量的用户。以上均为未叠加优惠码的标价。
